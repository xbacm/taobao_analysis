# 淘宝用户行为数据分析：电商转化与留存洞察

## 1. 项目背景与目标

本项目基于阿里天池公开的淘宝用户行为数据集（原始数据约 1.0015 亿条），使用 MySQL 和 Python 对用户行为进行清洗、统计与可视化分析。

项目围绕用户行为分布、探索性转化漏斗、行为路径转移、Cohort 活跃留存以及用户生命周期与回访间隔展开，旨在识别样本中的主要行为特征，为电商平台的用户运营与产品体验优化提供数据参考。

## 2. 数据与工具

### 数据来源与抽样
- **数据来源**：阿里天池 UserBehavior 数据集。
- **原始数据规模**：约 1.0015 亿条行为记录。
- **抽样方式**：基于 `user_id % 100 = 0` 筛选用户，获得约 100.2 万条行为记录，覆盖 9,895 名用户。该方法保留入选用户在原始数据中的行为记录，但不应直接视为严格随机抽样。分析结果主要反映该样本在指定观察窗口内的行为特征。
- **分析窗口**：2017 年 11 月 25 日至 2017 年 12 月 3 日，共 9 天。

### 技术栈
- **数据库**：MySQL 8.0
- **数据处理**：Python、Pandas、NumPy
- **数据可视化**：Matplotlib、Seaborn
- **分析环境与版本管理**：Jupyter Notebook、Git

## 3. 分析模块与目录结构

项目按照数据处理、行为分析、留存分析的顺序组织：

1. **数据清洗与时间维度处理**：检查数据完整性、重复记录及异常时间戳；筛选分析窗口，构建清洗表并提取日期、小时、星期等时间维度。
2. **用户行为分布与漏斗探索**：统计不同类型用户行为的分布；基于独立用户数（UV）比较浏览、加购、收藏和购买行为的覆盖情况，开展探索性漏斗分析。
3. **用户行为路径转移**：使用 SQL 窗口函数 `LAG()` 识别相邻行为事件之间的转移；通过转移矩阵及热力图观察不同用户行为类型之间的流转特征。
4. **同期群活跃留存分析（Cohort）**：根据用户首次活跃日期划分 Cohort；计算各 Cohort 在后续日期的活跃留存率，并对小样本 Cohort 进行筛选，对尚未完整观测的周期进行屏蔽。
5. **用户生命周期与回访间隔分析**：统计观察窗口内用户首次活跃日至末次活跃日之间的跨度；分析用户相邻活跃日期之间的间隔分布，观察样本用户的回访特征。

4. 核心发现
发现一：加购后再次浏览现象值得关注
数据证据：在观测窗口内，发生 cart -> pv 相邻行为转移的独立用户数为 5,677 人。

统计口径：统计至少发生过一次该类相邻行为转移的独立用户数（UV）。

业务解释与局限：加购后再次浏览可能反映用户正在比较商品，或将购物车作为暂存区使用。但该行为不能直接等同于购物车流失，仍需结合后续购买行为进行验证。

发现二：样本中存在较多浏览后直接购买的相邻行为转移
数据证据：发生 pv -> buy 相邻行为转移的独立用户数为 4,515 人，高于发生 cart -> buy 相邻行为转移的独立用户数（1,139 人）。

统计口径：统计观测窗口内至少发生过一次相应相邻行为转移的独立用户数（UV）。不同转移对应的用户群体可能重叠。

业务解释与局限：该结果反映了样本中的相邻行为转移特征，不代表互斥购买路径的占比，也不能直接推断用户的消费心理。购买机会、商品品类及行为序列等因素仍需进一步分析。

发现三：2017年11月25日 Cohort 的次日活跃留存表现较高
数据证据：以 2017 年 11 月 25 日为首次活跃日期的 Cohort，其 Day 1 留存率为 79.55%。

统计口径：按用户首次活跃日期划分 Cohort，以 Day 0 独立活跃用户数为分母计算后续周期的活跃留存率；剔除样本量小于 300 的 Cohort，并屏蔽尚未完整观测的周期。

业务解释与局限：该 Cohort 在次日表现出较高的活跃留存。但结果仅反映特定样本和观察窗口内的活跃情况，不能直接代表全量平台用户的长期留存或真实生命周期。

6. 注意事项与局限性
抽样局限：本项目基于 user_id % 100 = 0 筛选用户，不能保证样本严格随机，分析结果不应直接推广为全量平台结论。

观察窗口局限：数据分析仅覆盖 2017年11月25日至12月3日。生命周期跨度指观察窗口内首次活跃日至末次活跃日之间的时间差，不等于用户真实的完整生命周期。

漏斗口径：漏斗统计基于各行为类型的独立用户数，并未要求用户严格按照浏览、加购或收藏、购买的顺序完成全部步骤，因此属于探索性漏斗，而非严格的顺序转化漏斗。

路径分析口径：行为转移基于相邻事件，不能完整还原用户的购买旅程，也不能单独用于判断购买意愿或流失原因。

留存分析局限：Cohort 留存结果受样本规模和观察窗口影响。尚未完整观测的周期不应被解释为零留存。

性能说明：全量数据处理的耗时与资源需求取决于硬件配置、索引设计及查询方式。当前分析以抽样数据为基础，处理全量数据前应评估数据库资源与查询性能。
