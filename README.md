# 淘宝用户行为数据分析（电商转化与留存洞察）

## 1. 项目背景与目标
本项目基于阿里天池公开的用户行为数据集（原始数据约 1.0015 亿条），旨在通过数据清洗、漏斗分析、路径分析与同期群分析，洞察电商平台用户的转化特征与生命周期规律，为产品体验优化与精细化运营提供数据支持。

## 2. 数据与工具
- **数据源**：阿里天池 UserBehavior 数据集。
- **抽样说明**：抽样说明： 基于 user_id % 100 = 0 筛选用户，得到约 100.2 万条行为记录，覆盖 9,895 名用户。该方法保留了入选用户在原始数据中的行为记录，但由于采用用户 ID 取模筛选，样本不应直接视为严格随机样本；分析结论主要反映该样本在指定观察窗口内的行为特征。
- **分析窗口**：2017 年 11 月 25 日 至 2017 年 12 月 3 日（共计 9 天）。
- **技术栈**：MySQL 8.0 + Python (Pandas, Seaborn, Matplotlib) + Jupyter + Git。

## 3. 分析模块与目录结构
*   `data/`：存放聚合后的结果或抽样数据。
*   `sql/`：包含建表、抽样、清洗等 SQL 脚本。
*   `notebooks/`：Jupyter Notebook 分析文件。
    1.  **数据清洗与时间维度处理**：异常时间戳过滤、维度字段提取。
    2.  **用户行为分布与漏斗探索**：大盘行为概览、独立用户（UV）转化漏斗。
    3.  **用户行为路径转移矩阵**：基于 `LAG()` 分析行为流转，并可视化热力图。
    4.  **同期群留存分析（Cohort）**：用户首日活跃留存计算，包含小样本剔除与未观测周期掩码处理。
    5.  **用户生命周期与回访间隔分析**：观测窗口内用户生命周期跨度与回访间隔分布。

## 4. 核心发现

1. 加购后再次浏览现象值得关注

数据证据： 在观测窗口内，发生 cart -> pv 相邻行为转移的独立用户数为 5,677 人。

统计口径： 基于相邻行为事件转移，统计至少发生过一次该类转移的独立用户数（UV）。

业务解释与局限： 加购后再次浏览可能反映用户正在比较商品，或将购物车作为暂存区使用。但该行为不能直接等同于购物车流失，仍需结合后续购买行为进行进一步验证。

2. 样本中观察到较多浏览后直接购买的相邻行为转移

数据证据： 发生 pv -> buy 相邻行为转移的独立用户数为 4,515 人，高于发生 cart -> buy 相邻行为转移的独立用户数（1,139 人）。

统计口径： 统计观测窗口内至少发生过一次相应相邻行为转移的独立用户数（UV）。不同转移对应的用户群体可能重叠。

业务解释与局限： 样本中观察到较多浏览后直接购买的相邻行为转移，但该结果不代表互斥购买路径的占比，也不能直接推断用户的消费心理。购买机会、商品品类及行为序列等因素仍需进一步分析。

3. 2017-11-25 Cohort 的次日活跃留存表现较高

数据证据： 以 2017-11-25 为首次活跃日期的 Cohort，其 Day 1 留存率为 79.55%。

统计口径： 基于清洗后的样本数据，按用户首次活跃日期划分 Cohort，以 Day 0 独立活跃用户数为分母计算后续周期的活跃留存率；剔除样本量小于 300 的 Cohort，并对未观测周期进行屏蔽。

业务解释与局限： 该 Cohort 在次日表现出较高的活跃留存。但结果仅反映特定样本和观察窗口内的活跃情况，不能直接代表全量平台用户的长期留存或真实生命周期。


## 5. 如何运行
1.  **环境依赖**：Python 3.10+，MySQL 8.0+。所需依赖见 `requirements.txt`。
2.  **数据导入**：
    *   从 阿里天池 下载原始 `UserBehavior.csv`（约 3.7GB）。
    *   执行 `sql/01_create_raw_table.sql` 建表。
    *   使用 `LOAD DATA LOCAL INFILE` 将 CSV 导入。
    *   执行 `sql/02_create_sample_table.sql` 和 `sql/03_create_clean_table.sql` 进行抽样和清洗。
3.  **配置凭证**：复制 `.env.example` 并重命名为 `.env`，填入你的 MySQL 密码。
4.  **运行代码**：按顺序执行 `notebooks/` 目录下的 Jupyter 文件。

## 6. 注意事项与局限性说明
- **性能建议**：探索性分析基于 100 万行采样表，全量跑建议配置大数据引擎。
- **统计口径**：本报告的“生命周期”指代的是**当前观察窗口内**的首末活跃跨度，并非用户真实的完整生命周期。结论反映样本特征，非全量平台绝对结论。
